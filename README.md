# FavFind 🔖

**Your personal centralized video library for TikTok, Instagram Reels, and YouTube.**

Never lose a video again. Share any video from TikTok, Instagram, or YouTube directly into FavFind — it auto-detects the platform, lets you add tags + notes (or voice notes), and keeps everything beautifully organized and instantly searchable.

### ✨ Features

- **Native Share Support** — Tap Share → FavFind from any app (TikTok, Instagram, YouTube)
- **One-tap Quick Add** — Paste a link or use voice notes
- **Smart Auto-Detection** — Instantly recognizes TikTok, Instagram Reels, or YouTube
- **Powerful Search** — Fuzzy search across titles, notes, tags, platforms & dates
- **Multi-select Filters** — Combine platforms (TikTok + YouTube) with any hashtags
- **Clean Video Grid** — Platform icons, custom tags, notes, and one-tap “Open in App”
- **100% Offline** — Everything saved in localStorage (private & works without internet)
- **Mobile-First PWA** — Installable on iOS & Android with native feel
- **Dark Mode by default** — Clean, minimalist, and buttery smooth

### How to Use

1. Install as PWA (Add to Home Screen)
2. Open any video on TikTok / Instagram / YouTube
3. Tap **Share → FavFind**
4. Add tags or voice note → Save
5. Search, filter, and enjoy your personal video library forever

### Tech Stack

- Single-file HTML + Tailwind CSS
- Vanilla JavaScript (no build step)
- Web Speech API (voice notes)
- PWA + Share Target API
- localStorage persistence
